PENQUIN & HARENEE — ROMANTIC WEBSITE PROJECT

FILES
- index.html: webpage sections and content
- style.css: theme, responsive layout, effects and styling
- script.js: mobile menu, 10-question quiz, quiz feedback and proposal button
- media/couple_photo.jpg: photo supplied by you
- media/proposal_video.mp4: proposal video supplied/generated for this project
- media/aradhya.mp3: add the song file here to use the audio player

HOW TO OPEN
1. Extract the project folder if downloaded as ZIP.
2. Open index.html in Chrome, Edge, or another modern browser.
3. Internet is required for Google Fonts. The photo and proposal video are local files.
4. To add your audio, copy your legally obtained song file into media/ and name it aradhya.mp3.

NOTE
This is a front-end website. It does not store or send answers. The proposal buttons are local interactions.
